# Prepare an owner brief

Read only the selected input files. State the snapshot date and scope. Distinguish cancellation from a later booking: a cancelled appointment with a later booking is not a follow-up candidate.

Produce a local brief with facts, uncertainty, candidate next actions and a short question for the owner. Cite record IDs for every factual recommendation. When coverage is incomplete, describe what is unknown. Prepare recommendations for human review.

Read [the acceptance guide](references/acceptance.md). Do not send messages or change bookings as part of this work.
