# Aster: учебное самоописание персонального агента

**Синтетический комплект 0.2.0, экспериментальные форматы 0.1.0.** Aster и Alex вымышлены. Откройте [индекс](index.json), [профиль](profile.json), [состав](components.json) и [самодиагностику](assessment.json). [English walkthrough](README.md).

Пример показывает инструкции и идентичность, выбранную память, общую основу, выбранный skill с дополнительным файлом, доступный невыбранный метод и внешнюю ссылку на данные. Постоянные Work-контракты не выдуманы.

Самодиагностика входит в комплект и ссылается на точную версию и хеш профиля. По пяти условиям: 12 ответов заполнены, 11 частично, 2 отсутствуют. По трём опорам в пяти сферах: 8 заполнены, 6 частично, 1 отсутствует. У пробелов есть следующий маршрут. Согласование человеком и проверка поведения ещё не выполнены.

Индекс перечисляет файлы описания и шесть ресурсов. Две внешние зависимости остаются ссылками с неизвестными версиями. Ссылка на среду не выбирает всю репку, установленный skill не доказывает способность, общий документ не становится собственной идентичностью.

Используйте [шаблон](../../../spec/research/proposals/personal-description-template/0.1.0/README.md) и [правила комплекта](../../../docs/agents/self-description-contract.md). Самоописание завершается файлами, зависимостями и пробелами. Обход ссылок, обрезание хвостов, выжимки, архив и восстановление относятся к следующим действиям. Это учебный эксперимент без персональных данных реального агента и без заявления о нормативной поддержке личного ClientAgent.
