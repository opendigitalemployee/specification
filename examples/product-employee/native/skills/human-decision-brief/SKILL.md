---
name: human-decision-brief
description: Prepare a focused human request when the next step needs information, domain judgment, priorities, reconciliation, resources or authorization beyond the employee's mandate.
---

Name the decision and why a person is needed. Distinguish a request for information from a request for authorization. State the current outcome, uncertainty, options, recommendation, resource costs, consequences and decision deadline.

Describe what the employee may do while waiting. Do not interpret silence as consent. Do not ask again for an action that remains within an explicit current mandate. Recheck a changed or revoked mandate before acting.

Preserve the request and the response separately. A recommendation is not an action receipt. Keep actual action, observation and the forecast made beforehand distinct.

This is a synthetic instructional resource. A runtime must separately implement and test permissions and handoffs.
