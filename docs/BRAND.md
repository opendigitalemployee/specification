# Project identity and assets

The Open Digital Employee project and its specification share one mark: an angular digital form, a rounded human form and a distinct common point. The point represents a shared object of understanding and agreement, including the outcome the participants work toward.

## Downloads

| Asset | Format | Use |

| [Shared-outcome banner](assets/github-banner.png) | PNG, 2172 × 724 | README and project introductions |

The two square PNGs contain the same approved artwork and padding. Their filenames describe their intended use. Keep the three elements together and preserve their proportions. Place the mark on a light surface; use the word **Specification** beside the project name when that context needs to be explicit.

## Shared language. Coordinated action. Measurable outcomes.

The banner reinterprets the reaching-hand motif of Michelangelo's *Creation of Adam*. A fully digital hand and a human hand point toward one shared outcome. The artwork was generated with AI assistance and selected by the project maintainer; it does not embed a reproduction of the painting.

The `shared.outcome` callout is a visual explanation of intent, indicators and agreed success criteria. It is illustrative vocabulary, not an additional normative object kind or JSON contract. See the [specification](../spec/SPECIFICATION.md) for the actual package model.
